# ApexPlanet Cybersecurity Internship – Task 4

This repository contains my Task 4 submission on **Exploitation & System Security**, completed as part of my Cybersecurity & Ethical Hacking Internship at ApexPlanet Software Pvt. Ltd.

**Topics Covered:**

- Penetration Testing Methodology (Reconnaissance, Scanning & Reporting)
- Vulnerability Exploitation using Metasploit
- Reverse Shell & Post-Exploitation Analysis
- Password Auditing using Hydra and John the Ripper
- Phishing Awareness Simulation
- Static & Dynamic Analysis of a Benign Sample
- Firewall Configuration using iptables
- System Hardening & Service Security

**Tools Used:** Kali Linux, Metasploit Framework, Metasploitable 2, Nmap, Hydra, John the Ripper, smbclient, Python 3 and iptables.

**Key Learnings:**

- Understanding the penetration testing lifecycle.
- Exploring vulnerability exploitation and post-exploitation.
- Analysing password security and malware behaviour.
- Applying firewall rules and disabling unnecessary services.

**Note:** The SSH Hydra audit encountered a legacy compatibility issue. The John the Ripper demonstration used a self-generated test hash. Security patching was assessed but not performed because the target runs an unsupported Ubuntu 8.04 system.
